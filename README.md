# Personal AI OS (installable phone app)

Free to host. No server, no account on your phone, no subscription.

## Put it online (GitHub Pages, works from a phone browser)
1. Create a free account at github.com and make a new public repository.
2. Unzip this folder, then in the repository tap "Add file" > "Upload files" and upload everything (index.html, manifest.webmanifest, sw.js and the icons and fonts folders).
3. Go to Settings > Pages, choose the main branch and root folder, and save.
4. After a minute your link appears: https://YOURNAME.github.io/REPOSITORY/

Alternatives: Cloudflare Pages or Netlify Drop, both free.

## Install it
- iPhone (Safari): open the link, tap Share, then Add to Home Screen.
- Android (Chrome): open the link, tap the menu, then Install app (or tap Install in More).

## Good to know
- Everything is stored on the phone. Use More > Export backup regularly.
- Open the link once with internet; after that it also works offline.
- To update the app, upload a new index.html and reopen it twice.
